Morcas ChatBot

Ce projet vise à develloper une petite application de chatBot utilisant l'api de chat gpt .
le projet utilise node.js avec express comme serveur, handlebars comme moteur de rendu , et mongo DB avec mongoose comme base de donnés .
l'objectif est d'offrir aux utilisateurs la meilleure experience possible tout en s'assurant que leurs donnés sont bien securisés.
pour runner ce projet, il est essentiel d'avoir node.js installé sur son systeme.
il est important egalement d'avoir un serveur mongodb lancé, (vous pouvez telecharger MongoDB compass).
